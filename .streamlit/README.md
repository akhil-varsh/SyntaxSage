# Welcome to SyntaxSage! 🧙‍♂️

Thank you for using **SyntaxSage**, an AI-powered Python code analysis tool!

## 🚀 How to use:

1. **Enter your Python code** in the editor on the left
2. **Click "Analyze Code with AI"** to start the analysis
3. **View results** in the four analysis sections:
   - ⚡ **Code Execution**: See your code's output
   - 📝 **Code Summary**: AI-generated explanation
   - 💡 **Improvement Suggestions**: Optimization tips
   - ⏱️ **Complexity Analysis**: Performance insights

## 🤖 Powered by Gemma3 AI

This application uses Google's Gemma3 model for intelligent code analysis, providing you with:
- Deep understanding of your code's functionality
- Performance optimization suggestions
- Best practice recommendations
- Complexity analysis with Big O notation

## 🔧 Configuration

Check the sidebar to configure the Gemma3 API connection and test connectivity.

**Enjoy analyzing your code with AI!** ✨
